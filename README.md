2. **Omnipresent Documentation Synchronization**:
   - `SCHEMA.md`, `README.md`, and `ECOSYSTEM.md` must be updated synchronously in the exact same turn as any code change.
3. **Tri-Platform Contract Parity**:
   - Shared WebSocket event catalogs, IAM three-tier administrative hierarchies, and universal storage standards (`garage` self-hosted S3).
4. **Ruthless Test-Driven Verification**:
